# Code for paper *Bayesian Deep Generative Models for Multiplex Networks with Multiscale Overlapping Clusters*

## Reproduction Workflow

This repository contains the code and data used to reproduce the simulation studies and data analyses in the paper. The code is organized into shared implementation modules and experiment-specific scripts.

For each experiment, the corresponding `run_XXX.py` script performs posterior computation and saves the resulting outputs, while the corresponding `plot_XXX.py` script loads these outputs to generate the figures, tables, and numerical summaries reported in the main manuscript and supplementary material. The experiment-specific workflows and their correspondence to individual tables and figures are detailed below.

All Python scripts should be executed from the root directory of this repository. Posterior samples generated by the Gibbs samplers are not included due to their large storage requirements. All random seeds are fixed, so the posterior samples and reported results can be regenerated by running the corresponding scripts.

## Code

### Core implementation

The following files contain the core implementation of the proposed method and are imported by the experiment-specific scripts as needed:

- `class_M.py`: verify whether a matrix belongs to class $\mathcal{M}$
- `utils.py`: utility functions
- `simulate.py`: simulate data
- `spec_init.py`: spectral initialization
- `sample.py`: Gibbs samplers

These files provide the underlying functions used by the experiment-specific scripts below and generally do not need to be executed separately.

### Simulation studies

- `run_sim.py`: posterior computation for the main simulation study
- `plot_sim.py`: generate outputs for the main simulation study
- `run_sens.py`: posterior computation for the sensitivity analysis
- `plot_sens.py`: generate outputs for the sensitivity analysis
- `run_large_p_small_n.py`: posterior computation for the large-$p$, small-$N$ regime
- `plot_large_p_small_n.py`: generate outputs for the large-$p$, small-$N$ regime
- `run_hsbm.py`: posterior computation for simulated data from the hierarchical stochastic block model
- `run_hsbm_hcd.py`: fit hierarchical community detection by recursive partitioning (HCD) to the same simulated data
- `plot_hsbm.py`: generate outputs comparing the proposed method with HCD

For each simulation experiment, run the corresponding `run_XXX.py` script before its `plot_XXX.py` script. For the HCD comparison, run both `run_hsbm.py` and `run_hsbm_hcd.py` before `plot_hsbm.py`.

### Brain connectivity application

- `run_app.py`: posterior computation for the application to brain connectivity networks
- `plot_app.py`: generate outputs for the brain connectivity application

Run `run_app.py` before `plot_app.py`.

### Missing-edge prediction

- `run_mask.py`: posterior computation under the proposed model for masked brain connectivity networks
- `run_mask_dcmm.py`: fit the degree-corrected mixed membership model (DCMM) to the masked brain connectivity networks
- `plot_mask.py`: generate outputs comparing the proposed model with DCMM for prediction of missing edges

Run both `run_mask.py` and `run_mask_dcmm.py` before `plot_mask.py`.

## Data

The `data/` directory contains the data used for the brain connectivity application and associated analyses:

- `brain_connectivity_network_data.mat`: brain connectivity networks used for the main application and missing-edge prediction analysis (requires Git LFS)
- `cognitive_measure_data.npy`: cognitive measures used to study the relationships between inferred latent features and cognitive traits
- `cognitive_measure_names.txt`: names of the cognitive measures
- `brain_region_coordinates.npy`: coordinates of brain regions used for visualization on the cerebral cortex
- `brain_region_names.txt`: mapping of brain region indices to brain region names
- `atlas_desikan_killiany.nii`: Desikan--Killiany atlas used for visualization of networks on the cerebral cortex

The simulation studies do not require external input data; simulated datasets are generated by the corresponding simulation scripts using the functions in `simulate.py`.

## Output

The `output/` directory stores intermediate computational results and final outputs generated by the experiment-specific scripts.

- `simulation/`: outputs from the simulation studies, including:
  - main simulation study
  - sensitivity analysis
  - large-$p$, small-$N$ regime
  - comparison with HCD

- `application/`: outputs from the data analyses, including:
  - main application to brain connectivity networks
  - prediction of missing edges

The `run_XXX.py` scripts generate and save the computational results used by the corresponding `plot_XXX.py` scripts.

## Reproduction of Tables and Figures

The following table maps the computational tables and figures in the main manuscript and supplementary material to the scripts and input data used to generate them. Tables and figures generated by the same computational workflow are grouped together. For each analysis, the computation script(s) should be run before the corresponding plotting script.

| Manuscript results | Computation script(s) | Plotting script | Input data |
| --- | --- | --- | --- |
| Main simulation study: Supplementary Figures 2--4 and 6--8 and Table 5 | `code/run_sim.py` | `code/plot_sim.py` | Simulated data generated using `code/simulate.py` |
| Sensitivity analysis: Supplementary Table 1 | `code/run_sens.py` | `code/plot_sens.py` | Simulated data generated using `code/simulate.py` |
| Large-$p$, small-$N$ regime: Supplementary Figure 9 | `code/run_large_p_small_n.py` | `code/plot_large_p_small_n.py` | Simulated data generated using `code/simulate.py` |
| Comparison with HCD: Supplementary Table 2 | `code/run_hsbm.py`, `code/run_hsbm_hcd.py` | `code/plot_hsbm.py` | Simulated hierarchical stochastic block model data |
| Brain connectivity application: Main Figures 4--5; Supplementary Figures 10--13 and Table 3 | `code/run_app.py` | `code/plot_app.py` | `data/brain_connectivity_network_data.mat`, `data/cognitive_measure_data.npy`, `data/cognitive_measure_names.txt`, `data/brain_region_coordinates.npy`, `data/brain_region_names.txt`, `data/atlas_desikan_killiany.nii` |
| Missing-edge prediction: Supplementary Figure 14 | `code/run_mask.py`, `code/run_mask_dcmm.py` | `code/plot_mask.py` | `data/brain_connectivity_network_data.mat` |
